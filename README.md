# Pizzeria

A web-based pizza menu application built with HTML, CSS, and JavaScript.

## Features
- View the pizza menu with item count
- Add new pizza suggestions to the menu
- Remove pizzas from the menu
- Search and filter menu items
- Duplicate detection for menu items
- Input validation
- Responsive design for mobile devices

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Bootstrap 3.4
- Font Awesome 4.7

## How to Use
1. Click "Show Menu" to view available pizzas
2. Use the search bar to filter menu items
3. Type a pizza name and click "Add Pizza Suggestion" to add new items
4. Click the "x" button next to any item to remove it
